# Apple-Innovation-Leadership-RAG-System
Built a Retrieval-Augmented Generation (RAG) pipeline for semantic document analysis on "How Apple Is Organized for Innovation" HBR article. Implemented full RAG workflow: PDF text extraction with boilerplate removal, token-based chunking (256 tokens, 20-token overlap), OpenAI embeddings, ChromaDB vector store, and GPT-4 inference.
